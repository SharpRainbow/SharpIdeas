# SharpIdeas Android

### Описание

Android приложение для работы с сервисом SharpIdeas. Позволяет просматривать,
создавать и редактировать заметки, а также преобразовывать голос в текст. Для работы приложения
требуется соединение с интернетом, т.к. все данные хранятся на сервере SharpIdeas. 
Информация о серверном приложении доступна в репозитории [SharpIdeas API](https://gitlab.com/SharpRainbow/SharpIdeas).

### Возможности

- Просмотр списка заметок
- Создание и редактирование заметок
- Прикрепление изображений к заметкам
- Прикрепление аудиозаписей к заметкам
- Транскрипция и диаризация аудиозаписей
- Поиск по заметкам
- Добавление тегов к заметкам
